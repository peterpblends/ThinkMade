# AI stack update, 2026-10-23

The owner asked for a re-evaluation of ThinkMade's free AI, naming Phonon-31M, Moonshine Voice and EmbeddingGemma 2. Everything below still costs nothing to run.

## Why it was urgent

On 2026-08-16 Groq removed Llama 3.3 70B and Llama 4 Scout from its free tier. Those were ThinkMade's default script and image models, so every generation would have failed in production.

## What changed

| Job | Before | Now | Where it runs |
|---|---|---|---|
| Understand, choose models, plan, quality review | Groq Llama 3.3 70B | Groq **Qwen3.8-27B** (`reasoning_effort: low`) | Groq free tier |
| Research, scripts | Groq Llama 3.3 70B | Groq **gpt-oss-120b** (`reasoning_effort: low`) | Groq free tier |
| Coach Me | Groq Llama 3.3 70B | Groq **gpt-oss-20b** | Groq free tier |
| Photos and video frames | Groq Llama 4 Scout | **Gemma 4 31B** (`google/gemma-4-31b-it:free`) | OpenRouter free tier |
| Voices | Kokoro-82M | **Phonon-31M**, 25 English voices; Kokoro is the automatic backup | Worker (WebAssembly, no server) |
| Search vectors | Keyword hashing, 384 dimensions | **EmbeddingGemma 2** (q4), 512 dimensions | Worker; the API reaches it through an optional token-protected endpoint |
| Voice input | Groq Whisper | **Moonshine base on the listener's device**, when they turn it on in Settings; Groq Whisper otherwise | Browser |
| Video soundtracks | Groq Whisper | Unchanged (better for long audio) | Groq free tier |

Each Groq model has its own daily allowance, so spreading stages across three models roughly triples daily capacity.

## Changes to fit the free tiers

- **Request size.** Groq's free tier refuses any request over 8,000 tokens (prompt plus output). Stage models carry `tm_request_token_limit: 7500`: the client shortens the output allowance to fit, and the quality review splits long scripts into smaller windows. A request that can't fit fails with a clear 413 instead of a vague provider error.
- **Per-minute limits.** A 429 with a short reset (up to 90 s, from `retry-after` or Groq's reset headers) is now waited out inside the request, up to 4 times. Only long waits, such as the daily cap, send the job back to the queue. Before this, ordinary per-minute limits would have used up the job's retry budget and failed it.
- **Model params.** Admin model settings now pass extra fields, such as `reasoning_effort`, to the provider. Re-saving the same model keeps them. Reasoning preambles in `<think>` tags are ignored when parsing JSON.
- **Retired models.** On start, the worker moves any stored stage still on a retired Groq model, or on the old keyword-embedder default, to the new defaults. Admins' other choices are kept.

## Not verified

- **No Groq or OpenRouter key on this machine.** Qwen3.8, gpt-oss and Gemma 4 have not run a real ThinkMade episode. The model IDs, rate limits and reasoning parameters were checked against Groq's and OpenRouter's documentation and model lists on 2026-10-23. Script quality with these models needs a listen after deployment.
- **Request-size accounting.** The 8,000-token rule (prompt plus `max_tokens`) is how Groq documents it. The 7,500 margin assumes about 3.5 characters a token. Watch the first jobs' logs for 413 errors.
- **The Oracle VM (ARM).** Phonon and EmbeddingGemma 2 haven't run there yet. Both have ARM builds (WebAssembly and onnxruntime-node).
- **On-device Moonshine on real phones.** It was tested in desktop Chromium only, and needs a run in iOS Safari.
- **Moonshine v2 streaming** (the newest Moonshine Voice models) has no browser-ready ONNX export yet. ThinkMade uses Moonshine base (v1) in the browser. Revisit when v2 ships for Transformers.js.

## Update 2026-10-24: Qwen dropped

The first live run showed Groq caps `qwen/qwen3.8-27b` at 1,000 output tokens per minute on this account (an "OTPM" limit Groq applies to some free accounts), and refuses any request asking for more. A probe with the production key confirmed gpt-oss-120b and gpt-oss-20b accept 4,000-token outputs. Defaults are now gpt-oss-120b for research, plan and script, and gpt-oss-20b for understand, choose models, quality review and Coach Me. Stages no administrator has changed follow the new defaults automatically when the worker starts.

The same run also fixed:
- **Rejected keys.** A 401 or 403 now fails at once with a clear message instead of retrying as an outage.
- **Short plans.** A plan with fewer episodes than requested is sent back to the model to fix.
- **Progress screen.** It now ticks "Understanding your topic" when no photos were attached.

## Update 2026-10-25: free fallbacks and waiting out daily limits

- **Fallback chains.** Each stage now lists `tm_fallbacks`. When a model is out of allowance, failing, or refuses a request as too large, the next one answers. The order is Groq's other gpt-oss model, then OpenRouter's free Nemotron 3 Ultra 550B, then Nemotron 3.5 Lightning. Photos go Gemma 4 31B, then Nemotron 3.5 VL, then Gemma 4 26B. A fallback without an API key is skipped.
- **Live checks** on 2026-10-25 with the production keys:
  - Nemotron 3 Ultra (5 s) and Nemotron 3.5 Lightning (28 s) returned valid JSON.
  - Nemotron 3.5 VL described an image correctly, given 1,500 tokens.
  - Nemotron 3 Super returned 404 upstream, Gemma 4 was rate-limited upstream, and Inkling only works in agent tools.
- **Waiting out daily limits.** When every source is used up, the job waits until the earliest reset time the providers give (up to 6 hours at a time), and the progress screen says when it will continue. The cloud worker's check every 3 hours picks it up.
- **Rejected:**
  - Cerebras now needs a card.
  - GitHub Models' free tier is for prototyping only and is reported retired.
  - Mistral's free tier is for evaluation only.
  - Gemini's free tier was cut to about 20–100 requests a day, and Google trains on the data. It can still be added as a fallback with GEMINI_API_KEY.
